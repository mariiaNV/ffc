## 1) Конверсии и трекинг (обязательно)

### 1.1. Звонки из объявлений
Google Ads → Инструменты и настройки → Конверсии:
- Тип: **Звонки → Звонки из объявлений**
- Включить **Call reporting**
- Длительность звонка для конверсии: выберите **30 сек** или **60 сек** (лучше 60, если много «пустых» прозвонов)

### 1.2. Звонки с сайта (клик по tel:)
Через GTM (рекомендовано):
- Триггер: Click URL содержит `tel:`
- Тег: Google Ads Conversion (Website)

### 1.3. UTM (минимально)
`utm_source=google&utm_medium=cpc&utm_campaign={campaignid}&utm_adgroup={adgroupid}&utm_term={keyword}&utm_content={creative}`

## 2) Одна общая кампания (как вы просили)

### Кампания: Search | Одеса+Миколаїв+Ізмаїл | Дезінфекція/Дератизація/Фумігація | Calls

**Настройки:**
- Тип: Search
- Сети: только Search (без Display)
- Локации: Одеса, Миколаїв, Ізмаїл
	- В расширенных настройках гео: **Presence (люди в выбранных локациях)**
- Языки: **Russian + Ukrainian**
- Бюджет: **300 грн/день**
- Расписание: только когда вы реально берёте трубку (например 08:00–21:00)

**Ставки (без «магии», поэтапно):**
1) Старт (первые 7–14 дней): **Maximize Clicks** + ограничение CPC (чтобы не улетало), либо **Manual CPC**.
2) После появления стабильных конверсий (звонков): **Maximize Conversions**.
3) Потом: Target CPA (когда накопится статистика).

**Структура (3 ad groups, чтобы не смешивать запросы):**
1) `Дезинсекция (клопы/тараканы/блохи) — квартиры`
2) `Дератизация (крысы/мыши) — квартиры/дом/бизнес`
3) `Фумигация (склады/контейнеры/судна) — экспорт`
